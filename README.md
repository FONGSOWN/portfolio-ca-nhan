# Portfolio cá nhân — Sinh viên Công nghệ thông tin

Website Portfolio giao diện sáng, tối giản, responsive trên điện thoại và máy tính. Dự án sử dụng HTML, CSS và JavaScript thuần.

## 1. Cấu trúc thư mục

```text
portfolio-ca-nhan/
├── index.html
├── style.css
├── script.js
├── README.md
└── .gitignore
```

## 2. Chạy trên máy tính Windows

**Cách nhanh nhất**
1. Giải nén thư mục.
2. Mở thư mục bằng VS Code.
3. Mở `index.html` trên trình duyệt.

**Khuyến nghị**
1. Cài tiện ích Live Server trong VS Code.
2. Nhấp chuột phải `index.html` → **Open with Live Server**.

Website tĩnh nên không cần cài Python, Node.js hay cơ sở dữ liệu.

## 3. Tùy chỉnh thông tin trước khi nộp

Mở `index.html` và sửa các phần:
- Tên, ngành học, trường, mục tiêu nghề nghiệp.
- Email tại `[Email của bạn]` và `mailto:[EMAIL_CUA_BAN]`.
- Năm bắt đầu học và năm dự kiến tốt nghiệp.
- Mô tả dự án, link mã nguồn và link demo.
- Kỹ năng và mức độ thành thạo cho đúng năng lực thực tế.

Không đưa số điện thoại, địa chỉ nhà, mật khẩu hoặc thông tin riêng tư lên website công khai nếu không cần thiết.

## 4. Đưa website lên Render (miễn phí tùy chính sách hiện hành)

1. Tạo repository GitHub mới, ví dụ `portfolio-ca-nhan`.
2. Đưa `index.html`, `style.css`, `script.js`, `README.md`, `.gitignore` vào repository.
3. Đăng nhập Render và chọn **New + → Static Site**.
4. Kết nối repository GitHub vừa tạo.
5. Thiết lập:
   - **Build Command:** để trống.
   - **Publish Directory:** `.`
6. Chọn **Create Static Site** và chờ deploy hoàn tất.
7. Render cấp URL dạng `https://ten-website.onrender.com`. Mở link để kiểm tra menu, các mục và link liên hệ.

Tên nút hoặc giao diện Render có thể thay đổi theo thời điểm. Nếu repository có thư mục gốc khác, hãy đặt Publish Directory đúng vào thư mục chứa `index.html`.

## 5. Tạo file ZIP để nộp

Nén các file mã nguồn cần thiết. Không cần đưa `.git`, thư mục `.venv`, `node_modules` hoặc file chứa thông tin bí mật vào ZIP.
